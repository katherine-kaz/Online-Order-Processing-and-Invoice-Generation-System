# Online Order Processing and Invoice Generation System

##  Project Overview
The **Online Order Processing and Invoice Generation System** is a Java desktop application developed using Java Swing. It allows users to enter product details, calculate the total order amount, and generate a simple invoice.

The project demonstrates basic Java programming concepts and provides a simple graphical user interface for processing orders.

##  Features
- Enter product name, price, and quantity.
- Calculate the total order amount automatically.
- Generate an invoice displaying the order details.
- Validate user input and handle invalid entries.
- Reset the input fields.
- Save order details to a text file.

## 🛠️ Technologies Used
- **Programming Language:** Core Java
- **GUI:** Java Swing
- **IDE:** Eclipse
- **File Handling:** Java FileWriter and text files

##  Java Concepts Demonstrated
- Classes and Objects
- Constructors
- Encapsulation
- Methods
- Event Handling using ActionListener
- Exception Handling
- File Handling
- Packages

##  How to Run the Project

1. Download or clone this repository.
2. Open Eclipse IDE.
3. Select **File → Import → Existing Projects into Workspace**.
4. Choose the downloaded project folder and import it.
5. Open the `com.ordersystem` package.
6. Run `OrderGUI.java` as a Java Application.
7. Enter the product details and click **Generate Invoice**.
